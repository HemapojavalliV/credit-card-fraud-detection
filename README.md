# Credit Card Fraud Detection

This project uses a machine learning model to detect fraudulent credit card transactions.

## Features
- Data preprocessing and cleaning
- Logistic Regression model for classification
- Performance evaluation using accuracy and classification report

## Tech Stack
- Python
- Pandas
- Scikit-learn

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the project:
   python fraud_detection.py
   ## Output
The model predicts whether a transaction is fraudulent or not based on input features.
